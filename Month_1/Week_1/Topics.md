# Week 1 - Python Basics

## Learning Objectives

By the end of this week, you should be able to:

- Run a Python script from your editor or terminal
- Assign values to variables and identify common built-in types
- Use arithmetic operators and combine strings
- Read text input, convert numeric input, and display formatted results
- Build and explain a small interactive script

## Seven-day learning plan

### Day 1 - Setup and first program
Install Python and an editor, run `print("Hello, world!")`, and learn how to run a saved `.py` file. See [environment setup](./Environment_Setup.md).

### Day 2 - Variables and data types
Create descriptive variables. Practice with `str`, `int`, `float`, and `bool`, and inspect values with `type()`.

### Day 3 - Arithmetic and strings
Use arithmetic operators, string concatenation, repetition, and f-strings.

### Day 4 - Input, output, and conversion
Use `input()` and `print()`. Convert numeric text with `int()` or `float()` before doing arithmetic.

### Day 5 - Small programs
Combine the week's ideas to calculate an age estimate, a simple total, and a personalized message.

### Day 6 - Exercises and review
Complete [exercise 1](./Exercises/exercise_01.md), [exercise 2](./Exercises/exercise_02.md), and [exercise 3](./Exercises/exercise_03.md), then take the [quiz](./Quiz/Quiz.md).

### Day 7 - Mini project
Build the [Student Profile Generator](./Project/README.md) and check it against the project rubric.

Read [worked examples](./Examples/01_Examples.md) through [example 5](./Examples/05_Examples.md) as needed. The separate [weekly outline](./Week_1_Topics.md) points back to this guide.
