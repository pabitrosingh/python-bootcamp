# Week 1 resources

- [Python for Beginners](https://www.python.org/about/gettingstarted/) - official starting point for installing and learning Python.
- [Python tutorial: using the interpreter](https://docs.python.org/3/tutorial/interpreter.html) - running Python interactively and from scripts.
- [Python tutorial: an informal introduction](https://docs.python.org/3/tutorial/introduction.html) - numbers, text, variables, and strings.

The examples and exercises in this week are designed to be completed without additional courses or paid tools.
