🛠️ Step 1: Your Environment Setup (The Launchpad)
Before writing any Python code, you need a place to run it. We are going to set up a clean, professional environment just like real developers use.

Download Python: Go to the official website and download the latest version of Python. During installation, make sure to check the box that says "Add Python to PATH" (this is crucial!).

Install a Code Editor: Download and install VS Code. It is lightweight, powerful, and the industry standard.

Get the Python Extension: Open VS Code, click on the Extensions icon on the left sidebar (it looks like 4 blocks), search for "Python" by Microsoft, and click Install.

💻 Step 2: Your First Line of Code
Now, let's create your very first Python file.

Create a folder on your computer named python-bootcamp.

Open VS Code, go to File > Open Folder, and select that folder.

Create a new file inside that folder and name it day_1.py (the .py extension tells the computer it's a Python file).

Copy and paste the following code into that file:
# This is a comment. The computer ignores this line!
# We use comments to write notes to ourselves.

print("Hello, World!")

Run the code: Click the little play button ▶ in the top right corner of VS Code. Look at the terminal panel at the bottom—you should see Hello, World! printed out!
