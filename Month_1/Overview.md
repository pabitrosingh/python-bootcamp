# Month 1 - Python Foundations

## Goal

Build a foundation for writing small, correct Python command-line programs. Each week adds one major building block, and the final project combines them.

By the end of the month, you should be able to:

- Write and run Python scripts
- Use variables, common data types, input, and formatted output
- Make decisions with comparisons and conditional logic
- Repeat work with `for` and `while` loops
- Organize code into functions and handle expected input errors
- Build and manually verify a small menu-driven application

## Prerequisites and setup

No prior programming experience is required. Install Python 3.10 or newer and a code editor, then follow [Week 1 environment setup](./Week_1/Environment_Setup.md).

## How to study each week

1. Read the topic guide and type the examples into your own Python file.
2. Change example values and predict the result before running the code.
3. Complete the exercises without copying the worked examples.
4. Take the quiz before reading its answer key.
5. Build the weekly project from its requirements and check it against the rubric.
6. Keep a short note of one thing learned and one question to revisit.

Aim for 5-7 focused study sessions each week. A session can be 30-60 minutes; understanding and writing code matters more than finishing every page in one sitting.

## Completion criteria

You are ready to move on when you can explain the week's key ideas in your own words, complete the exercises, and run the project against its stated requirements. If you need the answer key or a worked example, revisit the concept and try a fresh input before moving on.
