# Week 3 - Repetition with loops

## Learning objectives

By the end of this week, you should be able to repeat work over a sequence with `for`, repeat while a condition remains true with `while`, and use loop control deliberately.

## Seven-day plan

1. Iterate through text and other sequences with `for`
2. Use `range()` for a known number of repetitions
3. Use `while` for condition-controlled repetition
4. Choose when to use `break` and `continue`
5. Combine loops and track results
6. Complete the [exercises](./Exercises/) and [quiz](./Quiz/Quiz.md)
7. Build the [Password Strength Checker](./Project/README.md)

## Loop safety

Before running a `while` loop, identify the condition that ends it and confirm that each pass can move toward that condition. A loop with no reachable stopping condition can run forever.
