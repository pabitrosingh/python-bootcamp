# Week 4 - Functions and input errors

## Learning objectives

By the end of this week, you should be able to define and call functions, pass arguments, return results, keep state local, and handle expected invalid input.

## Seven-day plan

1. Define and call functions
2. Parameters, arguments, and return values
3. Local scope and reusable logic
4. Catch expected conversion errors with `try` and `except`
5. Combine functions into a small command-line program
6. Complete the [exercises](./Exercises/) and [quiz](./Quiz/Quiz.md)
7. Build the [Student Report Card Generator](./Project/README.md)

## Function design checklist

- Give the function one clear job and a descriptive name.
- Pass the values it needs as parameters.
- Return calculated results instead of printing from every function.
- Keep temporary values local unless shared state is genuinely needed.
- Handle expected errors close to the input that may cause them.
