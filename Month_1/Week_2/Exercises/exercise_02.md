# Exercise 2 - Grade band

Ask for a score from 0 to 100 and display its letter grade using this scale: A = 90-100, B = 80-89, C = 70-79, D = 60-69, F = below 60.

Reject scores outside 0-100 with a clear message. Put the highest score threshold first.

**Test:** Try `100`, `90`, `89`, `60`, `59`, `-1`, and `101`.
