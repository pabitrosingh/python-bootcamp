# Exercise 3 - unittest to pytest

Write tests for a function that converts Celsius to Fahrenheit. Include normal values, the freezing point, and invalid input if your function validates types.

1. Implement the tests with `unittest.TestCase`.
2. Rewrite them as pytest functions with plain `assert` statements.
3. Use pytest parametrization for the valid examples.

**Test:** Run the standard-library version with `python -m unittest -v`. If pytest is installed, run the other version with `python -m pytest -v`.
