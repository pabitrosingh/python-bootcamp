# Exercise 3 - Nested list depth

Write a recursive function that returns the maximum nesting depth of a list. Treat a non-list item as depth zero and an empty list as depth one.

**Test:** `[]` has depth 1; `[1, 2]` has depth 1; `[1, [2, [3]]]` has depth 3.
