# Week 1 quiz - Lists and tuples

Try each question before checking [Answers.md](./Answers.md).

1. What is the index of the first element in a list? What does index `-1` select?
2. Given `values = [10, 20, 30, 40]`, what does `values[1:3]` return?
3. What is the difference between `append([3, 4])` and `extend([3, 4])`?
4. What does `numbers.sort()` return? What does `sorted(numbers)` return?
5. After `alias = original`, what happens to `original` if you append to `alias`?
6. How do you create a one-item tuple containing `"tea"`?
7. Is a tuple containing a list deeply immutable? Explain briefly.
8. Write a comprehension that squares each number in `range(4)`.
